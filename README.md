# 拾穗 Gleaner

把你和 AI 的对话收回来，拾起值得留下的部分，变成自己的笔记。

Bring your AI conversations home, glean what is worth keeping, and make it your own notes.

- 隐私说明 / Privacy: <https://thomas-melonesoda.github.io/gleaner/privacy.html>
- 问题和建议 / Questions and suggestions: [Issues](https://github.com/Thomas-Melonesoda/gleaner/issues)
