隐私说明Privacy

最后更新：2026 年 10 月 31 日Last updated: October 31, 2026

拾穗不收集你的任何数据。没有账号，没有使用统计，没有广告；我们也没有用来存放你数据的服务器。 Gleaner collects none of your data. There is no account, no usage analytics and no advertising, and we run no server that stores your data.

拾穗 AppThe Gleaner app

  • 导入的对话、你的笔记和备注、加进来的 PDF 和图片，都存在你自己电脑上的资料库文件夹里（Mac 上是 ~/Library/Application Support/Gleaner）。删掉这个文件夹，数据就全部删除了。 Imported conversations, your notes and comments, and the PDFs and images you add are kept in a library folder on your own computer (on a Mac, ~/Library/Application Support/Gleaner). Delete that folder and the data is gone.
  • 导出的 PDF、Word、Markdown 和学习笔记包，只保存到你选的位置。 Exported PDF, Word and Markdown files and study packs are saved only where you choose.
  • App 唯一主动联网的地方是检查新版本：每次启动时向 GitHub（api.github.com）查询一次最新的版本号。这次请求不带任何资料库内容，但和打开任何网页一样，GitHub 能看到你的 IP 地址。 The only time the app goes online on its own is to check for a new version: once per launch it asks GitHub (api.github.com) for the latest version number. The request carries none of your library, but as with any web page, GitHub can see your IP address.
  • 你在笔记里点链接时，链接用你的浏览器打开。 Links you click in your notes open in your browser.

浏览器扩展（Chrome、Edge）The browser extension (Chrome and Edge)

  • 扩展只在 ChatGPT（chatgpt.com）和 Claude（claude.ai）的网页上工作。 The extension works only on ChatGPT (chatgpt.com) and Claude (claude.ai).
  • 只有你点"导入"时，它才用你在这些网站已经登录的身份，读取当前这段对话：文字、你上传的和 AI 生成的图片、附件。附件可能存放在这些网站自己的文件地址上，扩展也只从那里下载。 Only when you click Import does it use your existing sign-in on those sites to read the current conversation: its text, the images you uploaded or the AI generated, and attachments. Attachments may be stored at those sites' own file addresses, and the extension downloads them only from there.
  • 读到的内容直接交给同一台电脑上的拾穗 App（本机地址 127.0.0.1，第一次使用时要输入 App 显示的配对码），不会发到其他任何地方。 What it reads goes straight to the Gleaner app on the same computer (the local address 127.0.0.1, after you pair them once with the code the app shows) and nowhere else.
  • 导入带交互图示的对话时，扩展会在你点击之后给当前标签页截一张图，截图同样只交给本机的 App。 When a conversation contains an interactive diagram, the extension takes a screenshot of the current tab after your click, and that screenshot also goes only to the app on your computer.
  • 扩展在浏览器里只保存两样东西：和 App 的配对凭据，以及你选的界面语言。 In your browser, the extension stores only two things: its pairing with the app and the interface language you chose.

Codex、Claude Code 和 Claude 应用插件Codex, Claude Code and the Claude app plugin

  • 你选择导入本机的 Codex、Claude Code 会话时，App 读取这两个工具保存在你电脑上的会话文件。 When you choose to import local Codex or Claude Code sessions, the app reads the session files these tools keep on your computer.
  • 在插件里说"存到拾穗"时，内容通过本机地址交给拾穗 App，不经过别的服务器。 When you say "save to Gleaner" in a plugin, the content is handed to the Gleaner app over the local address, with no other server in between.

这个网站This website

本站不用 Cookie，不做访问统计，字体和图片都从本站加载。和所有网站一样，托管网站的服务商可能会在访问日志里记下你的 IP 地址。 This site sets no cookies and runs no analytics; its fonts and images load from this site. As with any website, the hosting provider may record your IP address in its access logs.
