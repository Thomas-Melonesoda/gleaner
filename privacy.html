隐私说明Privacy

最后更新：2026 年 11 月 5 日Last updated: November 5, 2026

你的资料只在你自己的电脑上。没有账号，没有广告；我们没有用来存放你资料的服务器。App 每天会发送一次匿名使用统计（只有次数，不含任何资料内容），可以随时关掉，详见下面。 Your library stays on your own computer. There is no account and no advertising, and we run no server that stores your library. Once a day the app sends anonymous usage stats (counts only, nothing from your library), which you can turn off at any time; details below.

拾穗 AppThe Gleaner app

  • 导入的对话、你的笔记和备注、加进来的 PDF 和图片，都存在你自己电脑上的资料库文件夹里（Mac 上是 ~/Library/Application Support/Gleaner）。删掉这个文件夹，数据就全部删除了。 Imported conversations, your notes and comments, and the PDFs and images you add are kept in a library folder on your own computer (on a Mac, ~/Library/Application Support/Gleaner). Delete that folder and the data is gone.
  • 导出的 PDF、Word、Markdown 和学习笔记包，只保存到你选的位置。 Exported PDF, Word and Markdown files and study packs are saved only where you choose.
  • App 主动联网的地方只有两处。第一处是检查新版本：每次启动时向 GitHub（api.github.com）查询一次最新的版本号。这次请求不带任何资料库内容，但和打开任何网页一样，GitHub 能看到你的 IP 地址。 The app goes online on its own in only two places. The first is the update check: once per launch it asks GitHub (api.github.com) for the latest version number. The request carries none of your library, but as with any web page, GitHub can see your IP address.
  • 第二处是匿名使用统计，见下一节。 The second is anonymous usage stats, described in the next section.
  • 你在笔记里点链接时，链接用你的浏览器打开。 Links you click in your notes open in your browser.

匿名使用统计Anonymous usage stats

为了知道有多少人在用、哪些功能有用，App 每天最多一次（当天第一次打开时）向我们的统计服务 stats.gleanernotes.com 发送下面这些，第一次打开时会先提示你。只计数，不认人： So that we know how many people use Gleaner and which features help, the app sends the following to our stats service at stats.gleanernotes.com at most once a day (the first time you open it that day). It tells you first, the first time you open it. It counts; it does not identify you:

  • App 的版本号、系统（Mac 或 Windows）、芯片（Apple 芯片或 Intel）、界面语言。The app version, the system (Mac or Windows), the chip (Apple silicon or Intel) and the interface language.
  • 是不是这台电脑第一次发、是不是本周或本月第一次发，以及装了多久（不到 1 天、1–7 天、8–30 天、更久）。Whether this is the computer's first send, or its first this week or this month, and roughly how long the app has been installed (under a day, 1–7 days, 8–30 days or longer).
  • 上次发送以来，下面每件事各做了几次：How many times each of the following happened since the last send:
  • import_web 从浏览器扩展导入一份对话imported a conversation from the browser extension
  • import_plugin 从 Claude 应用或 Codex、Claude Code 插件存进来一份saved something in from the Claude app or the Codex / Claude Code plugins
  • import_session 导入一份本机的 Codex 或 Claude Code 会话imported a local Codex or Claude Code session
  • import_file 加进来文件（PDF、图片等）added files (PDFs, images and so on)
  • import_pack 导入学习笔记包imported a study pack
  • note_new 新建笔记created a note
  • excerpt 拾进笔记一段摘录gleaned an excerpt into a note
  • annotation 新建一条备注added a comment
  • export_pdf 导出 PDFexported a PDF
  • export_docx 导出 Wordexported a Word file
  • export_md 导出 Markdownexported Markdown
  • export_pack 导出学习笔记包exported a study pack
  • search 搜索searched
  • star 给轮次打星标starred turns
  • turns_tidy 删除轮次deleted turns
  • guide 打开使用说明opened the guide
  • 不发送：资料库里的任何内容、文件名和路径、对话或笔记的标题、网址、用户编号或设备编号、具体的使用时间。Never sent: anything in your library, file names or paths, conversation or note titles, web addresses, any user or device ID, or when exactly you used the app.
  • 统计服务不保存你的 IP 地址（它只用来防止有人刷数据）。明细保留 13 个月，之后自动删除。The stats service does not store your IP address (it is used only to stop abuse). The records are kept for 13 months and then deleted automatically.
  • 怎么关：第一次打开时的提示里点"关闭统计"，或者随时在菜单"帮助 → 发送匿名使用统计"里取消勾选。关掉后不再发送，还没发出去的次数也一起清掉。To turn it off, click Turn off in the notice the first time you open the app, or at any time untick Help → Send Anonymous Usage Stats in the menu. Once it is off nothing more is sent, and counts not yet sent are cleared.

浏览器扩展（Chrome、Edge）The browser extension (Chrome and Edge)

  • 扩展只在 ChatGPT（chatgpt.com）和 Claude（claude.ai）的网页上工作。 The extension works only on ChatGPT (chatgpt.com) and Claude (claude.ai).
  • 只有你点"导入"时，它才用你在这些网站已经登录的身份，读取当前这段对话：文字、你上传的和 AI 生成的图片、附件。附件可能存放在这些网站自己的文件地址上，扩展也只从那里下载。 Only when you click Import does it use your existing sign-in on those sites to read the current conversation: its text, the images you uploaded or the AI generated, and attachments. Attachments may be stored at those sites' own file addresses, and the extension downloads them only from there.
  • 读到的内容直接交给同一台电脑上的拾穗 App（本机地址 127.0.0.1，第一次使用时要输入 App 显示的配对码），不会发到其他任何地方。 What it reads goes straight to the Gleaner app on the same computer (the local address 127.0.0.1, after you pair them once with the code the app shows) and nowhere else.
  • 导入带交互图示的对话时，扩展会在你点击之后给当前标签页截一张图，截图同样只交给本机的 App。 When a conversation contains an interactive diagram, the extension takes a screenshot of the current tab after your click, and that screenshot also goes only to the app on your computer.
  • 扩展在浏览器里只保存两样东西：和 App 的配对凭据，以及你选的界面语言。 In your browser, the extension stores only two things: its pairing with the app and the interface language you chose.

Codex、Claude Code 和 Claude 应用插件Codex, Claude Code and the Claude app plugin

  • 你选择导入本机的 Codex、Claude Code 会话时，App 读取这两个工具保存在你电脑上的会话文件。 When you choose to import local Codex or Claude Code sessions, the app reads the session files these tools keep on your computer.
  • 在插件里说"存到拾穗"时，内容通过本机地址交给拾穗 App，不经过别的服务器。 When you say "save to Gleaner" in a plugin, the content is handed to the Gleaner app over the local address, with no other server in between.

这个网站This website

本站不用 Cookie，字体和图片都从本站加载。我们用 Cloudflare 网页分析统计访问量和来源网站，它也不用 Cookie。你点下载按钮时，网站会记一次点击：哪个系统的按钮、推广链接里的渠道标记（比如 ?ref=）、你从哪个网站来（只记域名）和页面语言。和所有网站一样，托管网站的服务商可能会在访问日志里记下你的 IP 地址。 This site sets no cookies, and its fonts and images load from this site. We use Cloudflare Web Analytics, which also sets no cookies, to count visits and referring sites. When you click a download button, the site records one click: which system's button, the campaign tag in a promotional link (such as ?ref=), the site you came from (its domain only) and the page language. As with any website, the hosting provider may record your IP address in its access logs.
